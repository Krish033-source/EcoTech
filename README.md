# VERDANT — Technology for a Living Planet

**Live website:** [VERDANT — Technology for a Living Planet](https://ecotech-livid.vercel.app/)

VERDANT is a single-page website about eco-friendly technologies. It explains how modern clean technologies work, what benefits they offer and what challenges remain.

## Features

- Bold neo-brutalist design in dark green, white and yellow
- Interactive technology explorer with six topics:
  - Solar Energy
  - Wind Power
  - Electric Mobility
  - Circular Technology
  - Green Hydrogen
  - Smart Grids & Storage
- Impact section with animated statistics
- FAQ section
- Responsive layout for mobile and desktop
- Simple animations: scrolling marquee, floating sticker and scroll reveal

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

No installation or build step is required.

## Deployment

The site is hosted on [Vercel](https://vercel.com/). Any commit to the main branch is deployed automatically.

## Data Sources

Impact statistics are rounded figures based on IRENA, IEA, UNEP and the UN Global E-waste Monitor.
